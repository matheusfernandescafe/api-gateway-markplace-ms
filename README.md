# API Gateway - Marketplace MS

**Marketplace MS** é um laboratório de estudo de arquitetura de microsserviços com Node.js, TypeScript e NestJS. Um ecossistema explorando padrões de comunicação, API Gateway e boas práticas de desenvolvimento distribuído.

Este diretório contém o **API Gateway**, desenvolvido utilizando [NestJS](https://nestjs.com/), que atua como ponto de entrada para toda a arquitetura.

## Tecnologias

- **Framework**: [NestJS](https://nestjs.com/)
- **Linguagem**: TypeScript
- **Testes**: [Vitest](https://vitest.dev/)
- **Linter**: [Oxlint](https://oxc.rs/docs/guide/usage/linter.html)
- **Outros**: Axios, Swagger, Helmet, Throttler
